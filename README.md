# Resume Tailor Skill

Resume Tailor帮助你根据目标岗位，从零撰写、改写或优化简历。它适用于产品、AI产品、运营、增长等互联网岗位，也可根据具体岗位要求调整重点，不限于秋招或实习。

你可以提供岗位JD、现有简历，或直接讲述做过的事。它会围绕岗位需要的能力提问，每轮最多3个问题，帮助你找出尚未写进简历的判断、协作和成果；遇到含糊或有歧义的表述，会先与你核对事实，再整理成清楚、经得起追问的经历。

## 怎么使用

在支持Skill的Agent中启用`resume-tailor`，提供目标岗位或JD，以及现有简历、经历素材或文件路径。你可以直接说明想从零撰写、按岗位改写，还是只优化某段经历；也可以提出篇幅、风格和提问方式要求。

例如：“使用resume-tailor，参考这份产品经理JD优化我的简历。先找出经历中缺少的关键信息，每轮最多问3个问题，最后给我一份可直接编辑的HTML简历。”

## 怎么安装

把下面这句话直接发给你使用的Agent：

> 请从[resume-tailor-skill仓库](https://github.com/shiguangjislj/resume-tailor-skill)安装`skills/resume-tailor`目录中的Skill；如已有同名Skill，请先比较再更新，保留我的个人素材；安装后验证是否可用，并告诉我在当前Agent中如何调用。

支持Skill的Agent通常可以照此安装；若当前Agent没有安装权限或不支持Skill，请让它说明限制和可行的使用方式。更详细的文件说明见[Skill文档](skills/resume-tailor/SKILL.md)。

## 你会得到什么

主要交付物是一份适配目标岗位的**HTML简历**。默认采用简约排版：蓝色用于标题和分隔线，正文保持清晰易读，少量重点用黑色加粗。打开HTML文件后，可以直接编辑正文；修改完点击“保存HTML”下载新版本，也可以通过浏览器的打印功能导出PDF。若你有自己的模板、颜色或篇幅要求，可以直接提出。

在梳理经历的过程中，Skill会持续更新**同一份本地经历素材库文件**，记录更完整的工作过程、证据和待确认信息。它不会在每轮改稿时把素材库全文贴到对话里。梳理完一段经历或准备结束对话时，你可以选择是否查看这份文件。

个人简历和素材库留在本地，不会随公开Skill仓库发布。换设备或Agent时，需要自行提供或迁移素材库。

## 写作依据

经历梳理参考[MIT的PAR简历写法](https://capd.mit.edu/resources/resumes-writing-about-your-skills/)等专业职业指导资料，同时检查个人职责、关键判断和结果证据。框架用于帮助组织真实经历，不会擅自补充没有发生的工作或成果。
